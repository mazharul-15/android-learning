# Android Resource Folders — Complete Notes

## `res/` Overview

Android resources are stored inside the `res/` folder.

```text
app/
└── src/
    └── main/
        ├── kotlin/ or java/
        ├── res/
        │   ├── drawable/
        │   ├── layout/
        │   ├── mipmap/
        │   └── values/
        └── AndroidManifest.xml
```

```text
drawable/ → images, vectors, shapes
layout/   → XML UI layouts
mipmap/   → launcher/app icons
values/   → reusable values and theme resources
```

---

## 1. `drawable/`

Stores normal drawable resources:

```text
PNG/JPG/WebP images
Vector Drawables
Shape Drawables
XML drawable resources
```

Example:

```text
res/drawable/
├── logo.png
├── profile.jpg
├── ic_student.xml
└── rounded_button.xml
```

Use an image in XML:

```xml
<ImageView
    android:layout_width="100dp"
    android:layout_height="100dp"
    android:src="@drawable/logo" />
```

Use it in Kotlin:

```kotlin
binding.ivLogo.setImageResource(R.drawable.logo)
```

### Shape Drawable

`drawable/` is also used for XML shapes:

```xml
<!-- res/drawable/rounded_background.xml -->

<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">

    <solid android:color="@color/blue" />
    <corners android:radius="12dp" />

</shape>
```

Use:

```xml
android:background="@drawable/rounded_background"
```

**Remember:** `drawable` is not only for images.

---

## 2. `layout/`

Stores XML files that describe UI screens or reusable UI layouts.

Examples:

```text
res/layout/
├── activity_main.xml
├── activity_student_info.xml
├── item_student.xml
└── fragment_home.xml
```

Example:

```xml
<LinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Hello" />

</LinearLayout>
```

Traditional loading:

```kotlin
setContentView(R.layout.activity_main)
```

With View Binding:

```kotlin
binding =
    ActivityMainBinding.inflate(layoutInflater)

setContentView(binding.root)
```

`activity_main.xml` generates `ActivityMainBinding`.

---

## 3. `mipmap/`

Mainly used for the **launcher/app icon**.

You may see density-specific folders:

```text
res/
├── mipmap-mdpi/
├── mipmap-hdpi/
├── mipmap-xhdpi/
├── mipmap-xxhdpi/
└── mipmap-xxxhdpi/
```

You may also see:

```text
mipmap-anydpi-v26/
```

Example in the manifest:

```xml
<application
    android:icon="@mipmap/ic_launcher"
    android:roundIcon="@mipmap/ic_launcher_round">
```

Simple rule:

```text
App/launcher icon
        ↓
     mipmap/

Normal images used inside the app
        ↓
     drawable/
```

---

## 4. `values/`

Stores reusable values and configuration resources.

Common files:

```text
res/values/
├── strings.xml
├── colors.xml
├── dimens.xml
├── themes.xml
└── styles.xml
```

The exact files depend on the project/template.

---

## 5. `strings.xml`

Stores reusable app text.

```xml
<resources>

    <string name="app_name">Student Manager</string>
    <string name="login">Login</string>
    <string name="email">Email</string>
    <string name="password">Password</string>

</resources>
```

Use:

```xml
android:text="@string/login"
```

instead of repeatedly writing:

```xml
android:text="Login"
```

Benefits:

```text
Centralized text
Localization support
Easy maintenance
Cleaner XML
```

---

## 6. `colors.xml`

Stores reusable colors.

```xml
<resources>

    <color name="blue">#2196F3</color>
    <color name="black">#000000</color>
    <color name="white">#FFFFFF</color>

</resources>
```

Use:

```xml
android:textColor="@color/blue"
```

or:

```xml
android:background="@color/blue"
```

---

## 7. `dimens.xml`

Stores reusable dimensions.

```xml
<resources>

    <dimen name="screen_padding">16dp</dimen>
    <dimen name="title_size">24sp</dimen>
    <dimen name="button_margin">16dp</dimen>

</resources>
```

Use:

```xml
android:padding="@dimen/screen_padding"
```

and:

```xml
android:textSize="@dimen/title_size"
```

Useful when the same dimension is used in many places.

---

## 8. `themes.xml`

Defines application/theme-level appearance.

Example:

```xml
<resources xmlns:tools="http://schemas.android.com/tools">

    <style name="Theme.StudentManager"
        parent="Theme.Material3.DayNight.NoActionBar">

        <!-- Theme configuration -->

    </style>

</resources>
```

The exact generated theme depends on your Android project and libraries.

Use theme resources for app-wide appearance rather than repeatedly applying the same configuration to every View.

---

## 9. `styles.xml`

Older or customized projects may contain:

```text
res/values/styles.xml
```

Example:

```xml
<resources>

    <style name="StudentTitle">
        <item name="android:textSize">24sp</item>
        <item name="android:textStyle">bold</item>
    </style>

</resources>
```

Use:

```xml
style="@style/StudentTitle"
```

Modern Android projects commonly use themes and theme-related resources.

---

## 10. Resource Naming Rules

Prefer:

```text
lowercase
numbers
underscore
```

Good:

```text
activity_main.xml
student_icon.xml
profile_image.png
student_item.xml
```

Avoid:

```text
ActivityMain.xml
Student-Icon.xml
Profile Image.png
```

Common naming conventions:

```text
activity_main.xml
fragment_home.xml
item_student.xml
dialog_delete.xml
```

## 11. Resource References

Resources are referenced in XML using:

```text
@type/name
```

Examples:

```xml
@drawable/logo
@layout/activity_main
@string/app_name
@color/blue
@dimen/screen_padding
@mipmap/ic_launcher
```

In Kotlin, generated resource IDs use `R`:

```kotlin
R.drawable.logo
R.layout.activity_main
R.string.app_name
R.color.blue
R.dimen.screen_padding
R.mipmap.ic_launcher
```

Think:

```text
XML:
@drawable/logo

Kotlin:
R.drawable.logo
```

## 12. `res/` vs `assets/`

Do not confuse `res/` and `assets/`.

### `res/`

Android knows the resource type:

```text
res/drawable
res/layout
res/values
res/mipmap
```

Resources are accessed through `R`:

```kotlin
R.drawable.logo
R.layout.activity_main
R.string.app_name
```

### `assets/`

`assets/` is for packaged files accessed through `AssetManager`.

Example:

```text
assets/
├── data.json
├── fonts/
└── html/
```

For your current learning, focus mainly on `res/`.

## 13. Complete Example

A Student Management App might have:

```text
res/
│
├── drawable/
│   ├── student_logo.png
│   └── rounded_button.xml
│
├── layout/
│   ├── activity_main.xml
│   └── activity_student_info.xml
│
├── mipmap/
│   └── ic_launcher
│
└── values/
    ├── strings.xml
    ├── colors.xml
    ├── dimens.xml
    └── themes.xml
```

Examples:

```xml
android:src="@drawable/student_logo"
```

```kotlin
setContentView(R.layout.activity_main)
```

```xml
android:text="@string/app_name"
```

```xml
android:textColor="@color/blue"
```

```xml
android:padding="@dimen/screen_padding"
```

```xml
android:icon="@mipmap/ic_launcher"
```

## 14. Simple Decision Rule

```text
Is it a normal image/drawable?
        ↓
    drawable/

Is it an XML UI layout?
        ↓
     layout/

Is it the app launcher icon?
        ↓
     mipmap/

Is it reusable text?
        ↓
 values/strings.xml

Is it a reusable color?
        ↓
 values/colors.xml

Is it a reusable dimension?
        ↓
 values/dimens.xml

Is it app-wide theme configuration?
        ↓
 values/themes.xml
```

---

## 15. Quick Memory Trick

```text
drawable → What it looks like
layout   → How the UI is arranged
mipmap   → App icon
values   → Reusable values/configuration
```

---

## 16. Quick Cheat Sheet

| Folder/File | Purpose | Example |
|---|---|---|
| `drawable/` | Images, vectors, shapes | `@drawable/logo` |
| `layout/` | XML UI layouts | `@layout/activity_main` |
| `mipmap/` | Launcher icons | `@mipmap/ic_launcher` |
| `values/strings.xml` | Text | `@string/app_name` |
| `values/colors.xml` | Colors | `@color/blue` |
| `values/dimens.xml` | Dimensions | `@dimen/screen_padding` |
| `values/themes.xml` | Theme configuration | `@style/Theme.StudentManager` |
| `values/styles.xml` | Reusable styles where applicable | `@style/StudentTitle` |

### Core rule

```text
UI XML        → layout
Normal image  → drawable
App icon      → mipmap
Reusable data → values
```
